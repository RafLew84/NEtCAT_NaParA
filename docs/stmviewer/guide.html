Instalacja STM Viewer — krok po kroku

Instrukcja dla Ubuntu 24.04 i Windows 11, komputerów Intel/AMD 64-bit. Stan programu: 3 listopada 2026. Zacznij od instalacji podstawowej; pozwala oglądać i wyrównywać filmy oraz zapisywać wyniki. Modele neuronowe można dołączyć później według osobnej instrukcji.

Co będzie potrzebne

  • Całe repozytorium programu, rozpakowane do zwykłego folderu.
  • Internet podczas instalacji. Podstawowy program później działa lokalnie.
  • Dla dużych serii: SSD i około 16 GB wolnego RAM. Małe filmy można otworzyć na słabszym komputerze.
  • Karta NVIDIA nie jest potrzebna do podstawowej instalacji. Dla modeli na GPU przyjmujemy co najmniej 8 GB VRAM; wymagania konkretnego modelu i rozmiaru filmu mogą być większe.

Repozytorium oznacza folder z kodem programu. Środowisko to osobny zestaw Pythona i bibliotek, przygotowany dla tej aplikacji. Utworzymy środowisko o nazwie stmviewer, aby nie zmieniać innych programów na komputerze.

Jeżeli masz już działający program w środowisku netcat, nie musisz instalować go ponownie. Do uruchomienia wystarcza aktywowanie netcat zamiast stmviewer i przejście do folderu repozytorium.

1. Przygotuj folder programu

Najprościej otrzymać od opiekuna projektu archiwum ZIP całego repozytorium w wersji przeznaczonej do pracy. Jeśli pobierasz je przez GitHub, wybierz właściwą gałąź, potem Code → Download ZIP. Domyślna gałąź może nie zawierać bieżących funkcji; tę instrukcję przygotowano na viewer/registration-difficult-movies.

W menedżerze plików wybierz Wyodrębnij wszystko… / Rozpakuj. Nie uruchamiaj programu z wnętrza ZIP-a. Nazwij rozpakowany folder NEtCAT. W jego środku powinny znajdować się m.in. foldery:

  • stmviewer
  • napara
  • nanotrack
  • tests
  • docs

Potrzebne są również pliki repozytorium leżące obok tych folderów. Samo skopiowanie stmviewer nie wystarczy. Przykładowe lokalizacje:

System Folder programu
Windows C:\NEtCAT albo inny folder, w którym możesz zapisywać
Ubuntu NEtCAT w katalogu domowym, czyli ~/NEtCAT

Możesz wybrać inną lokalizację. Wtedy w poleceniach cd poniżej wstaw własną ścieżkę, zachowując cudzysłowy.

2. Przygotuj Miniforge

Miniforge udostępnia Pythona i polecenie conda. Jeśli masz już działającą Minicondę/Anacondę/Miniforge, pomiń instalator.

Windows

  1. Na oficjalnej stronie Miniforge pobierz Miniforge3-Windows-x86_64.exe.
  2. Uruchom plik; wybierz instalację Just Me i folder dla swojego konta. Pozostaw dodawanie do PATH wyłączone.
  3. Po instalacji otwórz menu Start i wyszukaj Miniforge Prompt. Dalsze polecenia wpisuj w tym oknie.

Ubuntu

  1. Z tej samej strony Miniforge pobierz Miniforge3-Linux-x86_64.sh.
  2. Otwórz folder z pobranym plikiem. Kliknij tło prawym przyciskiem i wybierz Otwórz w terminalu.
  3. Wpisz:
bash Miniforge3-Linux-x86_64.sh
  1. Przejdź przez licencję, zaakceptuj ją po przeczytaniu, pozostaw domyślny folder instalacji. Na pytanie o inicjalizację conda odpowiedz yes.
  2. Zamknij terminal i otwórz nowy: Ctrl+Alt+T.

To procedura oparta na instrukcji autorów Miniforge, bez przypinania wydania instalatora.

3. Jak wklejać polecenia

Każdy wiersz to jedno polecenie. Wklej je i naciśnij Enter. Czekaj na zakończenie, zanim przejdziesz dalej.

  • Ubuntu: wklejanie przez Ctrl+Shift+V.
  • Windows Miniforge Prompt: zwykle Ctrl+V lub prawy przycisk myszy.
  • Nie przepisuj tekstu (base), (stmviewer), znaku > ani znaku $ z przykładów ekranu. To fragmenty wyglądu terminala.
  • Jeżeli zobaczysz >>>, jesteś w konsoli Pythona. Wpisz exit() i Enter, aby wrócić do terminala.
  • Po uruchomieniu programu terminal pozostaje zajęty do zamknięcia jego okna. To prawidłowe zachowanie.

4. Utwórz środowisko — tylko przy pierwszej instalacji

W terminalu / Miniforge Prompt:

conda create -n stmviewer python=3.12 pip

Gdy pojawi się pytanie Proceed ([y]/n)?, wpisz y i Enter. Potem:

conda activate stmviewer

Na początku wiersza powinno pojawić się (stmviewer). Python 3.12 to sprawdzony punkt startu, z dowolną aktualizacją poprawkową; nie jest to wymaganie jednej konkretnej wersji wszystkich bibliotek. Inne wydania Pythona wymagają sprawdzenia także wybranych modeli. Tworzenie i aktywację opisuje dokumentacja conda.

Jeżeli środowisko stmviewer już istnieje, użyj tylko conda activate stmviewer. Nie twórz go ponownie.

5. Przejdź do folderu programu

Windows, w Miniforge Prompt:

cd /d "C:\NEtCAT"

Ubuntu:

cd "$HOME/NEtCAT"

Własną ścieżkę możesz skopiować z paska adresu menedżera plików. W Ubuntu kliknij ten pasek lub użyj Ctrl+L. W Windows cd /d zmienia również dysk, np. z C: na D:.

6. Zainstaluj biblioteki

W aktywnym środowisku, z folderu programu:

python -m pip install --upgrade pip
python -m pip install -r stmviewer/requirements-ecc.txt
python -m pip check

Plik o nazwie requirements-ecc.txt zawiera cały zestaw podstawowy: interfejs, odczyt, sesje, Phase, korelację bez normalizacji, Tile+RANSAC, ECC, Optical Flow, AKAZE i zapis AVI. Nie trzeba osobno instalować requirements.txt.

Ostatnie polecenie powinno wypisać No broken requirements found. Samo to sprawdza zależności pakietów; działanie okna sprawdzisz za chwilę. Instalowanie z listy wymagań opisuje dokumentacja pip.

Nie instaluj osobno PyQt6-Qt6, PyQt6-sip ani kilku odmian OpenCV. PyQt6 dobiera swoje komponenty, a ten zestaw używa opencv-python. Odmiany OpenCV dzielą jeden moduł cv2, więc nie powinny współistnieć. Instrukcja autorów OpenCV.

7. Pierwsze uruchomienie i krótka próba

python -m stmviewer.main

Powinno pojawić się okno STM Viewer.

  1. Kliknij Otwórz STP/S94/MPP….
  2. W folderze programu otwórz tests/stmviewer/fixtures/registration/cpu.mpp.
  3. Kliknij Play, następnie Pause. Film ma trzy klatki.
  4. Wybierz metodę Phase i kliknij Rejestruj.
  5. Po zakończeniu wybierz original i aligned, porównując obrazy.
  6. Kliknij Zapisz sesję…, zapisz plik w swoim folderze z wynikami, potem otwórz go przyciskiem Otwórz sesję….

To kontrola instalacji na małym wzorcu. Nie jest oceną jakości dopasowania Twoich pomiarów. Dalsze kroki opisuje instrukcja obsługi.

8. Następne uruchomienia

Instalację wykonujesz raz. Przy następnej pracy wystarczą trzy polecenia.

Windows — otwórz Miniforge Prompt:

conda activate stmviewer
cd /d "C:\NEtCAT"
python -m stmviewer.main

Ubuntu — otwórz terminal:

conda activate stmviewer
cd "$HOME/NEtCAT"
python -m stmviewer.main

Nie zamykaj terminala podczas pracy programu. Zakończ przez krzyżyk okna STM Viewer albo Plik → Zakończ, a potem zamknij terminal. Zapisz wcześniej sesję, jeżeli chcesz kontynuować tę pracę.

9. Co oznaczają poluzowane wersje

Listy bibliotek stosują zakresy, np. PyQt6>=6.9,<7. Oznacza to wersję 6.9 lub nowszą z rodziny 6, zamiast jednej konkretnej poprawki. Podobnie potraktowano biblioteki numeryczne, OpenCV i większość zależności modeli. Instalator rozwiązuje ich wspólne wymagania.

Dolne granice są punktami startowymi deklarowanego wsparcia, nie dowodem, że każda kombinacja została przebadana. Górne ograniczenia oddzielają większe zmiany API. Już działającego środowiska nie trzeba aktualizować: zwykłe pip install -r ... pozostawia zainstalowaną zgodną wersję, o ile inne zależności nie wymagają jej zmiany. Zasady pip.

Kod modelu i jego wagi są osobną sprawą. Aplikacja sprawdza ich zgodność. RoMa wymaga obecnie romav2==2.0.1; inne wydanie odrzuci istniejący adapter. To wyjątek wynikający z działania programu, a nie ogólne przypięcie bibliotek.

Przed większą aktualizacją zachowaj działające środowisko i zapisz sesję. Opiekun może utworzyć drugie środowisko i sprawdzić aktualizację tam. Nie trzeba wykonywać aktualizacji przy każdym uruchomieniu.

python --version

Nie trzeba znać znaczenia wszystkich nazw. Lista pomaga odtworzyć problem. Szczegóły wykonanych sprawdzeń tej instrukcji są w raporcie instalacji.

STM Viewer — instrukcja obsługi

Program służy do przeglądania obrazów STM, wyrównywania kolejnych klatek i zapisywania wyników. Rejestracja oznacza tu wyznaczenie przesunięcia obrazów, aby rozpoznawalne struktury pozostawały w podobnym miejscu filmu.

Jeżeli program nie jest jeszcze zainstalowany, zacznij od instrukcji instalacji. Ta instrukcja opisuje dostępne funkcje, włącznie z edytorem parametrów AKAZE i LightGlue.

Pierwszy film w pięciu krokach

  1. Kliknij Otwórz STP/S94/MPP… i wybierz swój MPP.
  2. Obejrzyj kilka klatek przez Play/Pause i miniatury na dole.
  3. Wybierz metodę Phase, a następnie Rejestruj.
  4. Obejrzyj aligned i porównaj z original.
  5. Zapisz sesję, aby zachować pracę. MPP i AVI zapisuj jako dodatkowe wyniki, zależnie od ich przeznaczenia.

Phase jest wygodną próbą uruchomienia. Na trudnych filmach porównaj inne metody; jeden algorytm nie jest najlepszy dla wszystkich danych.

1. Wczytywanie danych

Otwórz STP/S94/MPP… lub Ctrl+O otwiera wybór danych.

Co wybierasz Jak zaznaczyć Co dostaniesz
Jeden MPP Jeden plik Wszystkie zawarte w nim klatki, w zapisanej kolejności
STP lub S94 Jeden albo wiele plików; Ctrl/Shift w oknie wyboru Serię obrazów, sortowaną naturalnie po nazwach, np. 2 przed 10
Sesja .stmsession Osobny przycisk Otwórz sesję… Obrazy i zapisany stan pracy

MPP otwieraj pojedynczo. Import wielu obrazów wymaga jednakowych wymiarów w pikselach. Nie wykonuje automatycznego skalowania. Gdy nowego zestawu nie uda się otworzyć, wcześniejszy pozostaje. Poprawny import zastępuje bieżącą serię — przed zmianą filmu zapisz sesję, jeśli chcesz do niej wrócić.

Jeżeli obok MPP jest plik .mpp.stmviewer.json, zostaw oba razem. Zawiera dodatkowe informacje potrzebne do pełnego odczytu historii i obszarów bez pomiaru.

2. Poruszanie się po filmie

Na dole są miniatury, numer klatki oraz ← Poprzednia / Następna →. Kliknięcie miniatury lub zmiana numeru wybiera jedną klatkę.

  • Play rozpoczyna odtwarzanie, Pause je zatrzymuje.
  • Tempo wynosi domyślnie 5 kl./s; można wybrać 1–30.
  • Pętla powtarza film. Bez niej odtwarzanie zatrzymuje się na końcu.
  • Kliknięcie Play na ostatniej klatce zaczyna film od pierwszej.
  • Ręczny wybór klatki zatrzymuje odtwarzanie.
  • Usuń klatkę usuwa ją z bieżącej pracy, nie z pliku źródłowego. Po usunięciu zobaczysz następną, a przy końcu serii poprzednią.

Numer bieżący i numer źródłowy mogą się różnić. Po usunięciu dwóch początkowych klatek dawna klatka 3 ma bieżący numer 1. Pochodzenie nadal można odczytać w lewym panelu.

3. Powiększenie, przesuwanie i jasność

Kółko myszy powiększa i pomniejsza obraz. Przytrzymaj lewy przycisk myszy na obrazie i przeciągnij, aby przesunąć widok. Przeciąganie zachowuje powiększenie. Przyciski + i − także zmieniają zoom.

Dopasuj pokazuje cały obraz w oknie. Nie zmienia liczby pikseli pomiaru ani nie wykonuje rejestracji. Przy przechodzeniu między klatkami zoom zostaje; original i aligned mają osobno zapamiętany widok.

Gamma rozjaśnia lub przyciemnia podgląd. Reset gamma przywraca 1. Nie zmienia wartości pomiarowych ani ustawień algorytmu rejestracji. Przy AVI można wybrać gamma podglądu albo neutralną.

Proporcje pikselowe pomijają skalę fizyczną z nagłówka przy wyświetlaniu. Użyj tej opcji, jeśli skala jest nieznana lub zastępcza. Nie poprawia ona metadanych i nie wyznacza rzeczywistej kalibracji.

4. Rejestracja całego filmu

  1. Usuń niepotrzebne klatki przed obliczeniem.
  2. Wybierz metodę w lewym panelu.
  3. Przy modelach wskaż wymagane pliki i urządzenie; możesz najpierw użyć Sprawdź model. Przy metodach podstawowych ten krok nie jest potrzebny.
  4. Kliknij Rejestruj.
  5. Poczekaj na zakończenie. Przycisk Anuluj rejestrację przerywa zadanie; wcześniejszy kompletny wynik pozostaje.
  6. Po sukcesie program pokazuje aligned. Obejrzyj film i przejścia, przy których struktury nadal skaczą.

Rejestracja w głównym oknie dopasowuje 2→1, 3→2 itd. i sumuje przesunięcia względem pierwszej klatki. Aktualnie oglądana klatka nie wybiera odniesienia. Ponowne obliczenie korzysta z wejściowych obrazów bieżącej serii.

original to dane wczytane do tej pracy, a aligned to aktualny wynik. Aby zmieścić przesuwane obrazy, program powiększa wspólny obszar. Nie zmniejsza przez to oryginalnych obrazów. Dopasowanie całego obszaru do ekranu może jednak sprawiać wrażenie oddalenia. Przesunięcia ułamkowe wymagają interpolacji; przy ostrych krawędziach mogą być widoczne wartości pośrednie.

Puste brzegi nie są nowym pomiarem. Żółty obrys pomaga odnaleźć zakres oryginalnej klatki. Brakujące obszary są prezentowane na jasnym tle; eksport AVI pozwala wybrać jego kolor.

Którą metodę wybrać

Grupa Dostępne metody Zastosowanie w pracy
Bez modeli i wag Phase, korelacja bez normalizacji, Tile+RANSAC, ECC, Optical Flow, AKAZE Porównanie różnych sposobów estymacji; działają na CPU
Z modelem Deep Matcher, EfficientLoFTR, RoMa v2, MatchAnything-ELoFTR, LightGlue + SuperPoint Dopasowania rozpoznawalnych elementów; wymagają przygotowania modelu
Warianty Deep Deep Matcher + ECC, Deep Matcher + lokalne fragmenty Dodatkowe doprecyzowanie lub ocena zgodności po Deep

Wszystkie te metody dostarczają pojedyncze przesunięcie X/Y na parę. Nie usuwają dowolnych deformacji wewnątrz klatki ani tearingu. Wcześniejsze obserwacje użytkownika na trudnych filmach wskazywały dobre wyniki Deep outdoor i RoMa, ale nie stanowi to gwarancji dla nowego pomiaru.

Wynik oznaczony jako niepewny wymaga obejrzenia. Komunikat o zbyt małej liczbie zgodnych wektorów oznacza brak dostatecznego poparcia dla przesunięcia przy tych ustawieniach, niekoniecznie błąd instalacji.

5. Parametry AKAZE i LightGlue

Otwórz Rejestracja → Parametry metod…. Małe okno może pozostać obok filmu.

  • Wybór metody w tym oknie zmienia formularz do edycji. Metodę obliczeń nadal wybierasz osobno w oknie głównym, parze albo grafie.
  • OK zatwierdza zmiany; Anuluj lub krzyżyk je odrzucają.
  • Przywróć domyślne dotyczy wyłącznie obecnie widocznej metody.
  • Zatwierdzone ustawienia dotyczą następnego obliczenia. Gotowy aligned i wcześniejsze wyniki nie są automatycznie przeliczane.
  • Obie konfiguracje są zapisywane w sesji.
Ustawienie Jak rozumieć zmianę
Próg detektora AKAZE / SuperPoint Mniejszy dopuszcza więcej punktów, również z zakłóceń
Próg dopasowań LightGlue Mniejszy dopuszcza więcej korespondencji, również błędnych
Maksymalna liczba punktów Większa może zwiększyć czas i zużycie pamięci
Tolerancja zgodności Dopuszczalna różnica wektorów w parze, w pikselach original
Percentyle Ograniczenie wpływu skrajnie jasnych i ciemnych próbek
CLAHE Wzmocnienie lokalnego kontrastu; może wzmacniać też szum
Pełne obliczenia LightGlue Wyłączenie wczesnego zakończenia i redukcji punktów

Zmieniaj jedno ustawienie naraz i oceniaj tę samą parę. Więcej znalezionych punktów nie oznacza automatycznie dokładniejszego wyrównania. Przygotowanie kontrastu zmienia tylko wejście algorytmu; nie zastępuje obrazów pomiarowych.

Obecnie edytor obejmuje te dwie metody. Rozszerzenie na pozostałe jest zaplanowane, ale nie jest jeszcze dostępne w tym oknie.

6. Obejrzenie i ręczna poprawa pary

Wybierz drugą klatkę problematycznej pary, np. 30 dla 29→30, i kliknij Porównaj parę…. Porównuj nakładkę 50/50 albo przełączaj klatkę bazową i przesuwaną. Zoom i gamma pomagają ocenić tę samą strukturę.

Jeżeli chcesz poprawić gotowy film:

  1. Najpierw musi istnieć kompletne dopasowanie całej serii.
  2. W sekcji Korekta całego filmu kliknij Popraw dopasowanie z filmu.
  3. Przesuń klatkę strzałkami o ±1 piksel w X/Y.
  4. Kliknij Zakończ korektę — to kończy edycję próby, ale jeszcze nie filmu.
  5. Kliknij Zastosuj do filmu — dopiero ten krok zmienia aligned i eksport.
  6. Sprawdź również dalsze klatki i zapisz sesję.

Poprawienie pary 1→2 przesuwa klatkę 2 oraz wszystkie następne. Zachowuje to ich wzajemne ustawienie. Usuń korektę tej pary z filmu cofa zastosowaną poprawkę tej pary.

Zachowaj do porównania przechowuje wariant pary obok nowej próby. Nie zapisuje filmu na dysk i nie stosuje przesunięcia do całej serii.

Po usunięciu klatki gotowy aligned pozostałych obrazów pozostaje dostępny, ale dalsza korekta filmu może wymagać nowej pełnej rejestracji. Udana nowa rejestracja zastępuje wcześniejsze ręczne poprawki; warto wcześniej zapisać sesję.

7. Dopasowanie wieloklatkowe

Ten tryb bierze pod uwagę relacje z kilkoma wcześniejszymi klatkami, zamiast sumować wyłącznie kolejne pary.

  1. Kliknij Dopasowanie wieloklatkowe….
  2. Wybierz metodę dopasowania par i okno do 3 lub do 5 poprzednich klatek. Sprawdź wybór metody w tym oknie — nie zakładaj, że jest taki sam jak w głównym panelu.
  3. Kliknij Oblicz kandydata grafu.
  4. Obejrzyj wynik LS i, jeśli chcesz, oblicz wariant Hubera.
  5. W grupie Aktywny film wybierz kompletny wynik.
  6. Kliknij Zastosuj wynik do filmu, aby stał się aligned w głównym oknie.
  7. Zapisz sesję.

LS znajduje wspólne położenia klatek z pomiarów par. Huber ogranicza wpływ relacji, które mocno odstają od wspólnego wyniku. Próg Hubera nie jest tolerancją detektora: reguluje wpływ rozbieżności w grafie. Limit iteracji określa maksymalną liczbę kroków obliczenia. Większy limit nie gwarantuje lepszego dopasowania ani zbieżności.

Samo obliczenie kandydata nie zmienia filmu głównego. Przy rozłącznym grafie lub nieukończonym Huberze Zastosuj wynik do filmu pozostaje nieaktywne; przeczytaj informację o kompletności i powodzie odmowy. Możesz wybrać inny kompletny wariant albo wykonać nowe obliczenie.

Ponowne liczenie Hubera korzysta z już zmierzonych par. Po zmianie parametrów algorytmu wykonaj nowe obliczenie grafu, jeśli chcesz ponownie dopasować obrazy. Tryb wieloklatkowy nie jest ograniczony do Deep Matchera.

Przywróć zachowany wynik pozwala wrócić do poprzedniego zastosowanego filmu. Zachowywany jest jeden poprzednik, nie pełna historia wszystkich prób.

8. Co i kiedy zapisać

Cel Wybierz Co zostaje zachowane
Kontynuowanie pracy jutro lub na innym komputerze Zapisz sesję… Samodzielny .stmsession: obrazy, stan pracy, wyrównanie, korekty, kandydaci i ustawienia
Dane obrazowe do dalszej analizy Zapisz MPP… Wybrana wersja całej pozostałej serii oraz towarzyszące metadane
Film do oglądania/prezentacji Plik → Zapisz AVI… Wyrenderowany obraz z wybranym tempem i wyglądem

Sesja

Użyj Zapisz sesję… lub Ctrl+Shift+S. Otwórz sesję… / Ctrl+Shift+O wznawia pracę z tego pliku. Obrazy są wewnątrz sesji — nie trzeba szukać oryginalnych plików MPP/STP/S94.

Sesja nie zawiera środowiska Python ani plików modeli. Na innym komputerze można obejrzeć gotowe wyniki bez modelu; do ponownego obliczenia trzeba udostępnić jego pliki i poprawić ścieżki.

MPP

Kliknij Zapisz MPP… lub Ctrl+S. W polu Typ pliku wybierz MPP original albo MPP aligned. Eksport obejmuje wszystkie pozostałe klatki, nie tylko aktualnie oglądaną.

Przenoś razem wynik.mpp i wynik.mpp.stmviewer.json. Gamma oraz zoom podglądu nie zmieniają pomiarów w tym zapisie. Aligned zawiera już interpolowane dane; białe wypełnienie braków jest odtwarzane jako brak pomiaru dzięki dodatkowym metadanym.

Po ponownym otwarciu aligned MPP program może nazywać ten widok original: to piksele wejściowe nowej pracy. Plik nie zawiera wcześniejszych oryginałów sprzed wyrównania. Do kontynuacji z oryginałami użyj sesji. Niektóre zapisane aligned mają brakujące próbki i nie nadają się do ponownej rejestracji obecnymi metodami.

AVI

Wybierz wersję original lub aligned, całą serię albo zakres, tempo 1–30 kl./s, gamma i kontrast. Możesz dodać podziałkę, numer klatki oraz dostępny czas pomiaru, a dla braków wybrać tło czarne, szare lub białe.

MJPG to kompresja stratna. FFV1 zachowuje piksele wyrenderowanego filmu, ale nie zastępuje MPP z wartościami pomiarowymi. AVI obejmuje pełny obraz; zoom na ekranie nie wybiera kadru eksportu. FPS filmu nie zmienia czasów pomiarów. Podziałka używa kalibracji danych; przy jej braku/proporcjach pikselowych pokazuje piksele.

9. Gdy wynik nie wygląda dobrze

Najpierw sprawdź nakładkę trudnej pary, nie tylko płynność odtwarzania. Algorytm może dopasować pasy zakłóceń zamiast struktury próbki.

Spróbuj innej metody, kontrolowanej zmiany jednego parametru, dopasowania wieloklatkowego lub ręcznej korekty. Porównuj w podobnym zoomie i przy tych samych klatkach. Zapamiętaj, czy numeracja jest przed czy po usunięciu klatek.

Przesunięcie X/Y nie naprawi każdego rozciągnięcia, uskoku linii czy zmieniającego się kontrastu STM. Zapis sesji pozwala wrócić do wcześniejszego wariantu bez ponownego liczenia.

Opcjonalne modele rejestracji — instalacja

Ta część jest potrzebna dopiero dla Deep Matchera, LightGlue, EfficientLoFTR, MatchAnything lub RoMa. Najpierw uruchom podstawowy program. AKAZE nie wymaga modelu ani wag.

Biblioteki instaluje pip. Wagi to osobne pliki wyuczonego modelu. Niektóre metody potrzebują również folderu kodu autorów. Program nie pobiera tych elementów podczas obliczeń.

1. Przygotuj Torch: wybierz CPU albo GPU

Zamknij STM Viewer. Otwórz terminal / Miniforge Prompt, aktywuj środowisko i przejdź do folderu programu zgodnie z instrukcją podstawową.

Bez karty NVIDIA — CPU

conda activate stmviewer
python -m pip install "torch>=2.9,<3" "torchvision>=0.24,<1" --index-url https://download.pytorch.org/whl/cpu

Obliczenia modeli będą działać na procesorze; na dużych filmach mogą trwać długo.

Z kartą NVIDIA — CUDA

Na oficjalnej stronie PyTorch wybierz Stable, swój system, Pip, Python i wariant CUDA zgodny z kartą oraz sterownikiem. Użyj wskazanego tam polecenia w aktywnym środowisku; początkowe pip / pip3 można zastąpić python -m pip. Dobieraj Torch i torchvision razem. Viewer deklaruje Torch 2.9 lub nowszy z rodziny 2; dla RoMa osobny zestaw zaczyna się od 2.11.

Nie kopiuj numeru CUDA tylko dlatego, że był użyty na innym komputerze. W razie wątpliwości dobór wariantu dla karty zleć opiekunowi stanowiska. Samo zainstalowanie pakietu o nazwie torch nie potwierdza obsługi GPU.

Sprawdź instalację:

python -c "import torch; print('Torch:', torch.__version__); print('CUDA:', torch.version.cuda); print('GPU dostepne:', torch.cuda.is_available())"

Dla wybranego GPU ostatnia wartość powinna być True. Dodatkowa krótka próba wykonania:

python -c "import torch; print((torch.ones(2, device='cuda') + 1).cpu())"

Oczekiwany wynik zawiera dwie wartości 2. Dla instalacji CPU pomiń drugie polecenie; GPU dostepne: False jest wtedy prawidłowe. Dobór platformy i binariów opiera się na instrukcji PyTorch.

2. Doinstaluj tylko wybrane metody

Polecenia wykonuj w środowisku stmviewer, z folderu repozytorium:

Metoda Polecenie
Deep Matcher i jego warianty python -m pip install -r stmviewer/requirements-deep.txt
LightGlue + SuperPoint python -m pip install -r stmviewer/requirements-lightglue.txt
EfficientLoFTR python -m pip install -r stmviewer/requirements-efficient.txt
MatchAnything-ELoFTR python -m pip install -r stmviewer/requirements-matchanything.txt

Każda lista dołącza potrzebny zestaw podstawowy. Nie używaj --upgrade bez potrzeby: zgodny zainstalowany Torch może zostać zachowany. Na końcu wykonaj python -m pip check i powtórz próbę GPU, jeśli go używasz. Uruchom program ponownie po instalowaniu bibliotek.

4. RoMa v2 — osobne środowisko

Aplikacja pozostaje w stmviewer (lub Twoim dotychczasowym netcat). RoMa uruchamia się jako osobny proces. Nie instaluj jej listy zależności do głównego środowiska.

Z folderu repozytorium:

conda create -n stmviewer-roma python=3.12 pip
conda activate stmviewer-roma

Zainstaluj parę Torch/torchvision wybraną według kroku 1, z Torch co najmniej 2.11 i torchvision co najmniej 0.26. Następnie:

python -m pip install -r stmviewer/requirements-roma-worker.txt
python -m pip check
python -c "import sys; print(sys.executable)"

Skopiuj ostatnią ścieżkę. W głównym programie w polu Python środowiska RoMa wskaż dokładnie ten plik python / python.exe. Wskaż też wagi i folder DINOv3 z tabeli. Zacznij od wariantu Turbo.

Na Linux RoMa zależy od skompilowanego fused-local-corr. Jego wydanie musi pasować do Torch/CUDA; sam pomyślny pip check nie sprawdza wykonania rozszerzenia na GPU. Zależności tego pakietu mogą narzucić dokładną wersję Torch mimo luźniejszej listy Viewera. Nie obchodź ich przez --no-deps. W razie błędu kompilacji lub ładowania potrzebny jest dobór zgodnej pary przez opiekuna środowiska. Opis projektu: RoMa v2.

Wymaganie romav2==2.0.1 pozostaje celowo ścisłe, ponieważ adapter sprawdza wersję i sumę kodu tego konkretnego modelu. Ogólne biblioteki mają zakresy. Nie oznacza to przetestowania każdej kombinacji; zawsze wykonaj Sprawdź model w wybranym urządzeniu.

Wróć do głównego środowiska przed uruchomieniem GUI:

conda activate stmviewer
python -m stmviewer.main

Dla dotychczasowej instalacji użyj conda activate netcat. Nie trzeba ręcznie aktywować środowiska RoMa przed każdym obliczeniem; program uruchomi wskazany interpreter.
